# เกม OX (Tic-Tac-Toe)

เกม OX สองผู้เล่น สร้างด้วย React + Vite + Tailwind CSS รองรับทุกขนาดหน้าจอ (มือถือ แท็บเล็ต เดสก์ท็อป) ธีมสว่าง

## คุณสมบัติ

- เล่นสองผู้เล่นบนหน้าจอเดียวกัน (ผลัดกัน X และ O)
- ตรวจจับผู้ชนะและไฮไลต์เส้นที่ชนะ
- แสดงสถานะเสมอ
- บันทึกคะแนนสะสม (X, O, เสมอ)
- ปุ่มเริ่มรอบใหม่ และปุ่มรีเซ็ตคะแนน
- ดีไซน์ responsive รองรับทุกอุปกรณ์

## การใช้งาน

```bash
npm install
npm run dev
```

เปิดเบราว์เซอร์ที่ URL ที่ Vite แสดง (ปกติคือ http://localhost:5173)

### Build สำหรับ production

```bash
npm run build
```
